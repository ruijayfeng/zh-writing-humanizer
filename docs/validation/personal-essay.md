# Validation Fixture: Personal Essay

## Input

那天走出医院的时候，我深刻意识到生命的脆弱与亲情的重要意义。母亲的背影不仅让我感受到岁月的流逝，更让我明白陪伴才是最长情的告白。

## Expected AI Traces

- Generic significance inflation: `生命的脆弱`, `亲情的重要意义`.
- Mechanical contrast: `不仅...更...`.
- Aphorism/slogan closer: `陪伴才是最长情的告白`.

## Acceptable Rewrite

那天从医院出来，我一直看着我妈走在前面。她走得比以前慢，左手还扶着墙。我那时候才有点慌：我总觉得还有很多时间，其实没有那么多。

## Gate

- Keep the emotional center.
- Replace slogans with concrete observed detail.
- First person is allowed because this is personal writing.
